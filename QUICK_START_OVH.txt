2️⃣ SSH NA VPS:
   ssh ubuntu@your-vps-ip

3️⃣ KONFIGURACJA:
   cd ~/mordzix
   cp .env.example .env
   nano .env
   # Wypełnij LLM_API_KEY (DeepInfra)

4️⃣ URUCHOM:
   chmod +x start.sh
   ./start.sh

5️⃣ OTWÓRZ PORT:
   sudo ufw allow 8080/tcp
   sudo ufw enable

6️⃣ TEST:
   http://your-vps-ip:8080
